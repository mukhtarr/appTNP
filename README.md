# appTNP

A Flutter-based Training and Placement Cell portal prototype with:

- role-based login and registration for Admin, Principal, TP Officer, TP Departmental Coordinator, and Students
- department and class management with batch tracking
- single-student entry and bulk CSV import with a sample template
- searchable student records with academic, skills, courses, internship, training, and profile details
- job and internship posting plus student applications/history
- dashboard analytics with batch-wise highlights and Excel/PDF export previews
- polished Material 3 styling, Google Fonts, Font Awesome icons, animated transitions, and dark/light theme toggle

- `/home/runner/work/appTNP/appTNP/lib/main.dart` – single-file Flutter prototype
